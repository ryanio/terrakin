# packages/ui/

`@terrakin/ui`: the browser pieces the app (`packages/client/`) and the staff app (`packages/admin/`) share. It has no build of its own; each app's Vite build bundles what it imports (`@terrakin/ui/dom`, `@terrakin/ui/tokens.css`, ...). Why the components live here: [decision 0041](../../docs/knowledge/decisions/0041-shared-ui-components-live-in-ui-with-their-styles-and-a-test.md).

## Rules

- **Build it once, here.** If a view needs something another view already draws (an avatar, a name with badges, a time, a state card, an empty note, a sheet, a checkbox row, a link to a profile or post), use the function below. If a piece shows up in a second place, move it here first. `packages/client/src/shared-components.test.ts` fails on the hand-built versions it knows about; add a pattern there when you add a component.
- **Every size comes from a scale.** Gaps, padding and margins of 4px or more are `--space-*`, font sizes `--text-*` (or a `clamp()` headline), corners `--r-*`, line heights `--leading-*`, weights `--weight-*`, all in `src/tokens.css`. Under 4px is a hairline or a nudge; geometry tied to a fixed size goes in a `calc()` that says what it measures. The same test checks every stylesheet.
- **Two page layouts.** A page is a `.column` (one centered column, `--page-narrow`) or a `.layout` (`--page-wide`). Build a `.layout` with `pageLayout(className, sideLabel)` in `ui.ts`, which gives a head over the main column and a 360px sidebar beside them from 1000px, or `wideLayout(className)` for a page of cards with no sidebar, whose main column takes the whole width (put the cards in a `.card-grid`). Below 1000px a `.layout` is one column: head, sidebar, main, or head, main, sidebar with `{ sideLast: true }` when the main column is what someone came for. Use a `.layout` for any page with something worth putting beside its main content (a balance, a form, a calendar, a ladder, who wrote it), and a `.column` for a form, a list read top to bottom, or a single thing. `.slot` keeps a place in the sidebar for a card that loads late. App stylesheets never set a page width or a sidebar grid of their own, and views never hand-build the layout's regions; tests fail on either.
- **Lay out with the primitives.** `stack` (a column, `.tight`, `.cards`, `.start`), `cluster` (a wrapping row) and `plain-list` go in a view's class list next to its own class (`stack paper card things-card`). Don't restate them in an app stylesheet; a test fails on a rule that does. A view's body inside `.page` is a `stack cards`, so its cards never touch, and a `.section-title` gets the room above it from the page, not from its own margin.
- **A component's styles live in `src/base.css`.** Never in an app's stylesheets (`packages/client/src/style.css` and the sheets beside its lazy views, `packages/admin/src/style.css`), which may add contextual rules (`.claim-agent .person-name`) but never redefine a base selector. The same test checks this, and that no selector is defined twice in one app's stylesheets.
- **One source for each kind of piece.** Every icon is a [Lucide](https://lucide.dev) glyph in `src/icons.ts`; add a line to the map, never draw one by hand. The client build fills `index.html`'s `<svg class="icon" data-icon="name">` from the same map. Every loading placeholder is built from `src/skeleton.ts`; add a shape there, not in a view. Every link to a resident or a post comes from `src/paths.ts`. A label that needs explaining gets `tip()`, never a `title` or `cursor: help`.
- **Keep the first load small.** `people.ts` loads `figure.ts`, and `tooltip.ts` loads `tooltip-bubble.ts`, with `import()`; never import either statically from code the first load holds. The client build fails over its first-load budget ([decision 0231](../../docs/knowledge/decisions/0231-the-client-build-leaves-out-zod-s-json-schema-code-and-draws.md)).
- **`toast.ts` and `copy.ts` stand alone.** They need only the DOM helpers and never import the protocol, so the docs pages' one script can load them ([decision 0211](../../docs/knowledge/decisions/0211-the-docs-pages-load-one-small-script-of-their-own-for-copy-b.md)). The apps import them through `ui.ts`.
- **An overlay owns one history entry.** `closeOverlay(dialog)` closes only that dialog, and the router calls `leaveOverlay` before every navigation so the new page replaces the overlay's entry.
- **Resident text is text.** `h()` in `src/dom.ts` puts strings in as text nodes, and `mentions.ts` turns text into text nodes and links, never HTML. Nothing here uses `innerHTML` or `insertAdjacentHTML`. `findLinks` takes only http and https with no login before the host, and `linkHref` sends anything off the site through `/away`.
- **Works under both apps' policies.** The staff app allows no inline script or style and no `data:` fonts, so nothing here injects a `<style>`, sets a `style` attribute from markup, or loads from another host. Setting styles through the CSSOM (`el.style.setProperty`, `el.style.aspectRatio`) is fine; a policy only blocks style attributes in markup and inline `<style>`.
- **No app state.** No tokens, storage, routes, or telemetry here. Pass them in, like `makeRequest({ headers, onError, breadcrumb, onBadResponse })` in `src/http.ts`, which says a 401 in the app's own words (`unauthorized`), never the server's.
- **The figure drawing has a DOM-free twin.** `src/figure-svg.ts` records `drawFigure` into `SvgPen` for the server's pictures, and `package.json` gives `src/figure-drawing.ts` as the types of `@terrakin/ui/figure-svg` so the server typechecks without the DOM; keep the two in step ([decision 0160](../../docs/knowledge/decisions/0160-pictures-by-link-are-public-cached-pngs-of-a-plot-a-look-and.md)).
- **A pattern motif fills and strokes, never clips.** A tile is recorded for cards by a pen whose clip paths don't travel with it. A motif stays inside its tile so tiles repeat without seams, and takes its colors from the theme's palette roles ([decision 0328](../../docs/knowledge/decisions/0328-prints-are-drawn-motifs-from-the-catalog-because-a-card-cann.md)).
- **Only our media.** Anything that takes a media URL checks it with `isMediaUrl` (`src/format.ts`).
- **Plain words, shared.** `src/safety.ts` holds the labels for report reasons, triage categories, and moderation actions, and `RULE_WORDS` (the rule a takedown notice cites), so the Report sheet, takedown notices, and the staff queue say the same thing.
- **Tests live with the apps** that use these pieces (`packages/client/src/*.test.ts`, `packages/admin/src/logic.test.ts`), so a change here runs both apps' tests through `pnpm verify`.

## Writing tests

A test for a piece here lives in the app test that uses it (the last rule above) and answers the four questions in the root [definition of done](../../AGENTS.md#definition-of-done). A test that copies a token list or restates a lookup table such as `REACTIONS` protects nothing.

## Where things are

- `src/tokens.css` design tokens on `:root`: colors, the scales, and the page rhythm (`--gap-page`, `--gap-section-head`). `src/base.css` resets, the primitives (`.stack`, `.cluster`, `.plain-list`), the page layouts (`.column`, `.layout`, `.slot`, `.card-grid`), the shared classes (`.paper`, `.card`, `.page-title`, `.section-title`, `.card-title`, `.pill`, `.pill-button`, `.btn-primary`, `.avatar`, `.icon`, `.hint`), and every component's styles.
- `src/ui.ts` the components: page layouts (`pageLayout`, `wideLayout`), rows (`itemRow`, `itemRows`), `progressBar`, `kindPill`, tabs (`linkTabs`, `pickTab`), `stateCard`, `emptyNote`, `errorLine`, `checkRow`, `chips`, `coinField`, `closeButton`, `cardBar`, `sheet`, `moreMenu`, `dropdown`, `onPressOutside`, `disclosure`, `moreButton`, `whileBusy`, `whileBusyAll`, `holdFocus`, `confirmTwice`, overlays (`openOverlay`, `closeOverlay`, `leaveOverlay`, `interceptPop`), `openPopover`, `landOnHash`, `shareLink`, `shareOnX`. It re-exports the toast and the copy helpers.
- `src/toast.ts` `toast`. `src/copy.ts` `copyBlock`, `copyButton`, `copyText`, `announce`.
- `src/people.ts` people: avatars (`avatarEl`, `paintAvatar`, `avatarPlaceholder`, `avatarStack`), `residentPerson`, `personLink`, `personLabel`, `badges` and its marks (`aiBadge`, `townsfolkBadge`, `partnerMark`, `flairChip`, `xMark`), `tagCard`, `ownerLine`, `keeperCards`, `who`, `quoteEmbed`.
- `src/tooltip.ts` `tip(el, text)`, a small bubble that says what a label means. `src/tooltip-bubble.ts` the bubble and its placement (`tipPlace`).
- `src/skeleton.ts` loading placeholders: `skeletonPage`, `skeletonPosts`, `skeletonCard`, `skeletonTiles`, `skLine`.
- `src/when.ts` `timeAgo`, `refreshTimes`. `src/motion.ts` `reducedMotion`, `REDUCED_MOTION`, `replay`, `countTo`, `showNumber`. `src/poll.ts` `visiblePoll`, `everyVisible`.
- `src/paths.ts` `profilePath`, `postPath`, `plot3dPath`, `collectionPath`.
- `src/dom.ts` `h()`, `icon(name)`, `SVG_NS`. `src/icons.ts` the icon map (`ICONS`, `iconSvg`). `src/icon-path.ts` `iconPath`, the same glyph as a `Path2D` for a canvas (the map's marks).
- `src/http.ts` `makeRequest`, the typed request helper that parses every response with a protocol schema.
- `src/format.ts` pure formatting: dates (`shortDate`), counts (`formatCount`, `plural`, `pluralWord`), `badgeText`, `mediaLayout`, `isMediaUrl`. `src/media.ts` post media, the model viewer, and `usePlaceTap`. `src/mentions.ts` and `src/links.ts` mentions and web addresses in post text (`appendRichText`, `findLinks`, `linkLabel`, `linkHref`).
- `src/looks.ts` themes, palettes, patterns, and hair (`lookPalette`, `paintMotif`, `hairOf`, `hairName`, `hasLook`), and the seasonal and earned colors (`HALLOWEEN_HEX`, `WINTER_HEX`, `THANKSGIVING_HEX`, `HANUKKAH_HEX`, `EARNED_HEX`). `src/figure.ts` the drawn figure (`drawFigure`, `paintFigure`, `garmentLook`, `drawFeelingIcon`, `signPx`). `src/feelings.ts` passes on `FEELINGS` from `@terrakin/figure`.
- `src/figure-svg.ts` the same figure as SVG path data, for the server's pictures by link (`figureDrawing`, `SvgPen`). `src/figure-drawing.ts` its DOM-free types.
- `src/item-art.ts` drawn pictures of items, wear, pots, and fish (`itemArt`, `itemArtImage`, `itemArtLoaded`, `thingPicture`, `thingArtImage`, `thingArtLoaded`, `piecePictureUrl`, and the pure `itemShapes` and `thingShapes`), and the sim's `CROP_HEX`, `GLAZE_HEX`, `onVine`, and `growth`, passed on.
- `src/ground-art.ts` paths and flooring (`paintGround`, `groundArt`). `src/pet-art.ts` pets (`petArt`, `drawPet`).
- `src/brand.ts` `BRAND_HEX` and the material colors drawings share (`WOOD`, `STRAW`, `STONE_HI`, ...), for canvas and WebGL.
- `src/safety.ts` the labels for report reasons, triage, and moderation, and `RULE_WORDS`. `src/reactions.ts` `REACTIONS`. `src/blocks.ts` the sim's `clearCost`, `blockName`, and `blockBackWords`, for the staff app's Shut homes card.
